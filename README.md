## 📌 Overview

The official personal developer portfolio for **Tushpendra Kumar**. Features an interactive hero section, project gallery, technical skill badges, downloadable resume, and direct contact avenues.

---

## ✨ Key Features

- **Hero Showcase:** Modern personal introduction with profile imagery, title banner, and quick bio.
- **Projects Gallery:** Highlighted software applications with live demo links and tech badges.
- **Skills Matrix:** Visual categorization of programming languages, backend frameworks, and databases.
- **Direct Contact:** Contact form and social media integrations (LinkedIn, YouTube, CodeByTushu).

---

## 💻 Tech Stack & Architecture

- **Frontend:** HTML5, Custom CSS3, JavaScript ES6+
- **Design Elements:** Custom Typography, CSS Hover Effects, Mobile Responsive Media Queries
